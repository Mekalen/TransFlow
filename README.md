# TransFlow Logistics Website

A modern, responsive logistics and freight services website for **TransFlow Logistics**, built to showcase services, company credibility, and customer engagement through quotes and contact channels. Designed with **Tailwind CSS** and **vanilla JavaScript**, optimized for speed, clarity, and scalability.

---

## 🚚 Overview

TransFlow Logistics is a single-page marketing and operations website for a logistics company operating across North America. It highlights services, company stats, testimonials, and provides an interactive quote request experience.

The site is fully responsive and optimized for both desktop and mobile users.

---

## ✨ Features

* **Responsive Navigation**

  * Fixed header with desktop and mobile menus
  * Smooth scrolling between sections
* **Hero Section**

  * Clear value proposition and strong CTAs
* **Company Stats**

  * Active trucks, client count, coverage, and delivery performance
* **Services Section**

  * Dynamically rendered service cards (via JavaScript)
* **Quote Request**

  * Interactive quote form rendered via JavaScript
* **About & Testimonials**

  * Company background and client trust indicators
* **Contact Section**

  * Phone, email, and headquarters location
* **Modern UI**

  * Built with Tailwind CSS utility classes
  * Lucide icons for clean, scalable visuals
* **Lightweight**

  * No frameworks or build tools required

---

## 🛠 Tech Stack

* **HTML5**
* **Tailwind CSS (CDN)**

## 🚀 Getting Started

### 1. Clone or Download

```bash
git clone https://github.com/your-username/transflow-logistics.git
```

Or download and extract the ZIP file.

### 2. Open Locally

Open `index.html` in any modern browser:

```bash
open index.html
```

No server, build step, or dependencies required.

## ⚙️ JavaScript Functionality

The `script.js` file is responsible for:

* Mobile menu toggle
* Smooth scrolling navigation
* Rendering services grid
* Rendering testimonials
* Rendering quote form
* Handling basic UI interactions

> The shipment tracking section is currently commented out and can be enabled when backend or API support is added.
